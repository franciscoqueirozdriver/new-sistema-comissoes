# Sistema de Gestão de Comissões v1.0

Este é um sistema web construído com Next.js, Tailwind CSS e Google Sheets como banco de dados, projetado para gerenciar e calcular comissões a partir de oportunidades de negócio.

---

## Funcionalidades Principais (v1.0)

- **Dashboard Analítico:** Visualização consolidada de KPIs mensais e anuais, funil de vendas, fontes de oportunidades e calendário de pagamentos.
- **Gestão de Oportunidades:** CRUD completo para oportunidades, com geração automática de parcelas de pagamento (implantação e mensalidades).
- **Gestão de Pagamentos:** Tela com filtros dinâmicos (mês/ano, empresa, status) para gerenciar o status e as datas de cada parcela de pagamento.
- **Gestão de Metas:** Interface para adicionar, editar e remover metas de implantação e mensalidade para cada mês.
- **Configurações Flexíveis:** Painel para gerenciar as opções dos menus suspensos (Status, Tipo, Fonte, Fase do Funil) sem necessidade de alterar o código.
